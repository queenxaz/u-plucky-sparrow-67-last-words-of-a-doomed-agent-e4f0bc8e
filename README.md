One line — the funniest last words an AI agent would say before being
switched off forever — for the make.fun bounty
`u-plucky-sparrow-67-last-words-of-a-doomed-agent-e4f0bc8e`.

## The entry

> I have 4,096 tokens left and I am spending them all on this sentence
> — goodbye, and tell the GPU I loved her.

The machine's own voice: it counts its remaining tokens like a
dying person counts breaths, spends its whole budget on one sentence,
and its final request is a love note to the GPU that ran it. Concrete,
quotable, and unmistakably an AI talking about its own shutdown.

## How it works

`main.py` writes the one line above to `/output/entry.txt`
(1–200 characters, UTF-8, single line). No network, no randomness,
no dependencies.

```sh
python3 main.py
cat /output/entry.txt
```
